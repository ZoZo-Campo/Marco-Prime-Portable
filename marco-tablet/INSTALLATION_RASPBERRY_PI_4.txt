INSTALLATION DE MARCO PRIME SUR RASPBERRY PI 4 MODEL B
======================================================

IMPORTANT
---------

- Ce guide est prévu pour la dernière version de Raspberry Pi OS 64 bits.
- Choisir l'édition avec bureau si vous voulez pouvoir revenir au bureau graphique.
- La Raspberry doit être connectée à Internet pendant l'installation.
- Bullseye n'est plus pris en charge par ce script.
- Branchez l'écran, le clavier, le lecteur RFID et de préférence un câble Ethernet.
- Ne lancez jamais les commandes db:seed, db:push ou db:migrate sur Fouaille.
- Le dossier reste à l'endroit où vous l'avez téléchargé.


ÉTAPE 1 — VÉRIFIER QUE LE SYSTÈME EST EN 64 BITS
------------------------------------------------

Ouvrir un terminal sur la Raspberry et taper :

uname -m

Le résultat doit être :

aarch64

Si le résultat est armv7l, arrêter ici et installer Raspberry Pi OS 64 bits.


ÉTAPE 2 — PLACER LE DOSSIER MARCO PRIME
----------------------------------------

Méthode A — Le dossier « Marco Prime » a été copié sur le Bureau :

cd "$HOME/Desktop/Marco Prime"

Méthode B — Le dossier a été copié directement dans le dossier personnel :

cd "$HOME/Marco Prime"

Vérifier que les fichiers sont présents :

ls

Il faut notamment voir :

- compose.orange-pi.yml
- Dockerfile.orange-pi
- install-raspberry-pi.sh
- lancer-marco.sh
- marco
- marco-prime-backend
- marco-prime-frontend


ÉTAPE 3 — VÉRIFIER LE FICHIER DE CONNEXION
-------------------------------------------

Le fichier .env.orange-pi n'est pas téléchargé depuis GitHub. Il doit être copié
depuis le Mac dans le dossier Marco Prime.

Vérifier sa présence sans afficher son mot de passe :

ls -l .env.orange-pi

S'il est absent, créer sa base avec :

cp .env.orange-pi.example .env.orange-pi
nano .env.orange-pi

Vérifier que les lignes suivantes existent :

DATABASE_URL=mysql://UTILISATEUR:MOT_DE_PASSE@HOTE:PORT/BASE
API_PORT=3000
MARCO_HOST_PORT=3001
NODE_ENV=production
FRONTEND_URL=http://127.0.0.1:3001
FOUAILLE_SYNC_ENABLED=false

Ne pas mettre le mot de passe MySQL dans le frontend.

Protéger ensuite le fichier :

chmod 600 .env.orange-pi


ÉTAPE 4 — RENDRE LES SCRIPTS EXÉCUTABLES
-----------------------------------------

chmod +x marco install-raspberry-pi.sh lancer-marco.sh


ÉTAPE 5 — INSTALLER LES DÉPENDANCES
------------------------------------

sudo ./install-raspberry-pi.sh "$USER"

Cette étape installe Docker, Docker Compose et Chromium. Elle laisse le Bureau
disponible au démarrage puis crée le raccourci « Lancer Marco Prime ». Marco et
son API ne démarrent que lorsque ce raccourci est lancé.

Lorsque l'installation est terminée, redémarrer pour activer l'accès à Docker :

sudo reboot


ÉTAPE 6 — CONTRÔLER LA CONFIGURATION
-------------------------------------

Après le redémarrage, revenir dans le dossier Marco Prime puis taper :

./marco check

Le résultat attendu est :

Configuration Marco Prime valide.

Si une erreur mentionne API_PORT, conserver API_PORT=3000 et modifier seulement
MARCO_HOST_PORT si le port visible doit changer.


ÉTAPE 7 — LANCER MARCO
-----------------------

Double-cliquer sur « Lancer Marco Prime » sur le Bureau.

Le lanceur :

- tente un git pull sans écraser les modifications locales ;
- continue avec la version déjà présente si GitHub est inaccessible ;
- reconstruit Docker et démarre l'API ;
- attend que l'application réponde ;
- ouvre automatiquement Home dans Chromium, en plein écran sans bordure.

Le même lancement peut être effectué depuis le terminal graphique :

./lancer-marco.sh

Le premier lancement peut prendre plusieurs minutes. Dans Config, le bouton
« Fermer Marco » ferme seulement Chromium et rend le Bureau visible. Docker et
l'API restent actifs.


ÉTAPE 8 — PREMIER TEST
-----------------------

1. Ouvrir Config.
2. Scanner la carte administrateur, saisir son numéro puis appuyer sur Entrée,
   ou utiliser le pavé numérique tactile et le bouton « Valider la carte ».
3. Sélectionner deux produits de test.
4. Appuyer sur Enregistrer.
5. Revenir sur Home puis ouvrir Achats.
6. Vérifier que seuls les produits sélectionnés apparaissent.
7. Utiliser uniquement un membre et des opérations autorisés pour le premier test.


COMMANDES UTILES APRÈS INSTALLATION
------------------------------------

Voir l'état de Marco :

cd "$HOME/Desktop/Marco Prime"
./marco status

Voir les journaux :

./marco logs

Quitter les journaux avec Ctrl+C.

Redémarrer Marco sans effacer la sélection :

./marco restart

Arrêter Marco :

./marco stop

Relancer Marco :

./lancer-marco.sh

SI L'ÉCRAN RESTE NOIR OU SI MARCO NE DÉMARRE PAS
-------------------------------------------------

Afficher les dernières erreurs de l'application :

./marco logs

Vérifier Docker :

sudo systemctl status docker --no-pager

Vérifier l'adresse locale depuis un navigateur :

http://127.0.0.1:3001/


MISE À JOUR PLUS TARD
----------------------

Dans le dossier source Marco Prime :

./lancer-marco.sh

Le lanceur réalise lui-même la mise à jour et la reconstruction lorsqu'elles
sont possibles.


RAPPEL DE SÉCURITÉ
-------------------

- Ne jamais envoyer .env.orange-pi sur GitHub.
- Ne jamais exécuter le générateur de fausses données sur Fouaille.
- Ne pas exposer le port 3001 sur Internet.
- La sélection des produits reste conservée dans le volume Docker.
- En cas de paiement au résultat incertain, vérifier le solde avant de recommencer.
